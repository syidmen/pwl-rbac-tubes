# Anggota 1 - Project Lead / Admin

## Tujuan

Menjaga repo tetap rapi, mengatur merge PR, dan melakukan testing akhir.

## File Utama

- `README.md`
- `package.json`
- `tsconfig.json`
- `.gitignore`
- struktur folder project

## Tugas

- Menyiapkan struktur folder awal.
- Menyiapkan script project.
- Mengatur branch dan pull request.
- Memastikan semua tugas memakai studi kasus Inventaris Barang Sederhana.
- Review PR anggota lain.
- Merge PR anggota ke branch `review`.
- Melakukan testing akhir di branch `review`.
- Merge branch `review` ke `main` jika sudah aman.
- Memperbaiki konflik merge jika ada.

## Output Yang Diharapkan

- Repo bisa dijalankan.
- Struktur folder jelas.
- README utama singkat dan mudah dipahami.
- Semua PR sudah direview sebelum merge.
- Branch `review` dipakai untuk integrasi.
- Hasil akhir project berhasil dites.
- Fitur akhir minimal mencakup login, RBAC, dan CRUD item inventaris.
